🧭 Fitur MTB & catatan

Profil elevasi dan total tanjakan berguna untuk menilai beratnya rute. Data peta mungkin tidak membedakan jalur tanah, aspal, jalan pribadi, atau trail resmi dengan sempurna.

Bagian yang memakai layanan eksternal

Peta: OpenStreetMap melalui tile publik.

Routing: server OSRM / OpenStreetMap Routing Project untuk mengikuti jaringan jalan. Profil sepeda dan lari yang tersedia tergantung server; fallback dapat memakai rute kendaraan dan tidak ideal untuk MTB.

Elevasi: Open-Elevation API. Hasil berupa perkiraan, bukan data survei atau pengukuran GPS barometrik.

Penyimpanan: lokal di browser. Tidak ada akun/cloud, sinkronisasi, feed sosial, segmen kompetitif, atau database pengguna pada versi ini.

Peta © OpenStreetMap contributors. Aplikasi ini prototipe mandiri dan bukan produk resmi Strava. Routing/elevasi membutuhkan internet dan layanan publik bisa membatasi permintaan.
